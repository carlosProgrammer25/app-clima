App Clima
Digite o nome de uma cidade e veja a temperatura atual.

Como funciona
Escreva o nome da cidade no campo de busca

Clique em pesquisar

O app mostra: temperatura, país e descrição do clima

Como rodar no seu computador
git clone https://github.com/carlosProgrammer25/app-clima.git
cd app-clima
npm install
npm start

Tecnologias usadas
React

API do OpenWeatherMap

CSS

Arquivos principais
Search.js (lógica do app)

Search.css (estilização)

index.html (página principal)
